# Labels de triagem

As skills falam em termos de cinco funções canônicas de triagem. Este repositório usa labels no GitHub para duas delas; as outras três são representadas pelo estado da issue ou por um comentário de triagem.

| Função em mattpocock/skills | Label no nosso rastreador | Como representar                                        |
| --------------------------- | ------------------------- | ------------------------------------------------------- |
| `needs-triage`              | —                         | Issue sem label de estado; entra na fila de não triadas |
| `needs-info`                | —                         | Comentário de triagem com as perguntas pendentes        |
| `ready-for-agent`           | `pronto-para-agente`      | Aplicar o label na issue                                |
| `ready-for-human`           | `pronto-para-humano`      | Aplicar o label na issue                                |
| `wontfix`                   | —                         | Fechar a issue com o comentário de justificativa        |

Quando um skill mencionar uma função, aplique o label correspondente quando ele existir. Para as funções sem label, use o estado ou o comentário indicado na tabela.

Os labels de categoria `bug` e `enhancement` continuam sendo usados para classificar a issue. Os únicos labels de **estado** de triagem são `pronto-para-agente` e `pronto-para-humano`.
